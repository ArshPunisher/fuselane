Every network. One fast download.

Fuselane downloads one file over your Wi-Fi, Ethernet and phone at the same time, then fuses the parts.

Measured on real machines

  • 18.6 s A 246 MB 1080p video, over Wi-Fi and Ethernet at once.
  • 113 + 117Mbps Ethernet and Wi-Fi on the same Mac, each measured by the network check.
  • 50MB/s About that for a 300 MB file over Ethernet and Wi-Fi, byte for byte the same.

How one file rides every network

No VPN, no relay server, no admin rights. It all happens on your computer.

Split

Fuselane asks the server for the file in parts, the standard way a browser resumes a download.

Spread

Each part goes over whichever network is free. Faster networks simply carry more parts, so their speeds add up.

Fuse

Every part is checked before it joins the others. You get one file, exactly the one the server sent.

A server that doesn't allow parts sends the whole file over one network.

Picks up where it stopped

Checked, not guessed

Parts only join if they come from the same file. Paste a SHA-256 to be sure.

New: Fuse Send

Send a file of any size. Nothing to upload.

Pick a file, copy the link, send it however you like. The receiver gets it straight from your computer, encrypted on the way and checked when it lands. No cloud in the middle, so no size limit, no expiry, no account.

  • End-to-end encrypted: the key lives only in the link
  • No size limit: 4 GB or 400 GB, same link
  • Same Wi-Fi: straight away. Across the internet: over IPv6, or when the sender's router has UPnP on
  • Survives a restart: the same link keeps working
