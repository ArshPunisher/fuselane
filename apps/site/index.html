How one file rides every network

No VPN, no relay server, no admin rights. It all happens on your computer.

Split

Fuselane asks the server for the file in parts, the standard way a browser resumes a download.

Spread

Each part goes over whichever network is free. Faster networks simply carry more parts, so their speeds add up.

Fuse

Every part is checked before it joins the others. You get one file, exactly the one the server sent.

A server that doesn’t allow parts sends the whole file over one network.

Fuse Send

Send a file of any size. Nothing to upload.

Pick a file, copy the link, send it however you like. The other person’s Fuselane gets it straight from your computer, encrypted on the way and checked when it lands.

  • End-to-end encrypted: the key lives only in the link
  • No size limit: 4 GB or 400 GB, the same link
  • Same Wi-Fi: straight away. Across the internet: over IPv6, or when your router has UPnP on
  • Survives a restart: the same link keeps working
  • Keep Fuselane open until it arrives; it can wait in the tray

Good to know before you install

What Fuselane can’t do, or can’t do yet, in plain words.

All the limits, in the guide

  • Some servers send one stream

    A server that refuses parts sends the file over one network. It still downloads.

  • Different lines add up

    Two cables to the same router share one internet line, so they won’t be faster together. Wi-Fi plus your phone’s mobile data will.

  • Torrents look for peers on one network

    Peers are spread across your networks, but the DHT and tracker lookups go out over your default network.

  • A VPN that takes everything

    If a VPN routes all traffic through one connection, Fuselane sees one connection.

  • macOS asks once

    Fuselane isn’t notarized by Apple (that needs a paid account), so you choose Open Anyway once. The install script skips the step.

  • Windows may warn

    Until code signing through the SignPath Foundation is approved, SmartScreen may stop it. Choose More info, then Run anyway.
