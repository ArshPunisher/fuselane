One download.
Every network.

Fuselane splits each download across your Wi-Fi, Ethernet and phone at once, then joins the parts into one verified file.

Download All downloads

Free and open source. macOS, Windows and Linux.

Faster, without a VPN or a server in the middle

Every network works at once. Each part of the file is fetched over whichever network is free, so their speeds add up.

Nothing breaks when one drops. Unplug the cable or lose the phone signal and the others carry on. Quit or crash, and it resumes where it stopped.

The file is checked. Parts are only kept if they come from the same file, and you can verify a SHA-256.

Private by design

No account, no analytics, no crash reporting. Fuselane talks to the servers in your links and to a signed update feed, nothing else unless you turn on optional per-network DNS lookups. Read the privacy policy.

Open source under Apache-2.0. Every release is built in public by GitHub Actions; app updates are signed and checked before they install.
