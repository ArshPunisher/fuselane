How it works

How does Fuselane combine my connections?

It splits a download into parts and fetches them over every network you have at the same time, each part over whichever network is free. Faster networks simply take more parts. When they are all in, the parts are checked and joined into one file.

Which connections can I combine?

Any your computer shows as a network: Wi-Fi, Ethernet, a phone tethered over USB, a second Wi-Fi or USB adapter. They help most when they come from different internet lines (your home Wi-Fi plus your phone's mobile data, say). Two cables to the same router share one line, so they won't be faster together.

Does it speed up my whole computer?

No. It speeds up what you download with Fuselane: links you add, torrents, and big downloads the browser extension hands over. Everything else uses your normal connection.

Will it eat my phone's data?

Only as much as you let it. Set a speed limit or a monthly allowance for each network (for example, 5 GB a month on the phone), turn on Slow mode during calls, or let it download only at night. When a network reaches its allowance, Fuselane stops using it until the reset day.

Does it work with torrents?

Yes: magnet links and .torrent files, with a choice of files before anything downloads. Peers are spread across your networks, and sharing after a download is off unless you turn it on.

Do servers mind?

Fuselane asks for parts the standard way (byte ranges), as browsers do when they resume. If a server limits connections, Fuselane backs off; if it doesn't allow parts at all, the file comes over one network.

Can it download videos from YouTube and other sites?

Yes, if you install the free yt-dlp tool (and ffmpeg for HD). Paste the video's page and choose Get the video from this page; pick a quality and Fuselane downloads it over every network. yt-dlp only finds the links; Fuselane never bundles it. Download only what you have the right to.

What does the network check send, and to whom?

It downloads a 25 MB test file per network from Cloudflare's public speed test, times short connections to 1.1.1.1 and one name lookup. Nothing is uploaded and no results leave your computer unless you send the report yourself.

Fuse Send

How does Fuse Send work?

In Fuselane, open Send and pick a file. You get a link; send it any way you like. When the other person opens it, their Fuselane fetches the file straight from yours, encrypted on the way, and checks it matches before saving it. Nothing is uploaded anywhere, so there is no size limit and nothing expires.

Do I need to keep Fuselane open while sending?

Yes: the file comes from your computer, so keep Fuselane open (it can sit in the tray) until it arrives. If you close it or restart, the share comes back by itself and the same link keeps working. You can also have it stop after one full copy is sent.

The receiver can't reach me. Why?

The file comes straight from your computer, so the receiver's Fuselane has to be able to connect to it. On the same Wi-Fi or office network that just works. Across the internet it works when your router lets it in: over IPv6, which most internet providers now give out, or over IPv4 when UPnP is on in the router's settings. Fuselane has no server in the middle to relay files, which is why it's free and has no size limit.

Who can open a Fuse Send link?

Anyone with the whole link, so share it like a password. The key is in the part after #, which browsers never send to a server; the share page reads it on the receiver's own device and hands it to Fuselane. Others on the network see only a random identifier, never the file's name or contents.

Installing and trust

Why does my computer warn me the first time I open it?

Fuselane is free and doesn't pay for Apple's notarization, and its Windows signing through the SignPath Foundation is still being set up. So macOS asks you to choose Open Anyway once (in System Settings, Privacy & Security), and Windows may say More info, then Run anyway. The Mac install command and Homebrew skip the step. See Download for each system.

Is it stable?

It is in beta. Downloads survive a dropped network, sleep, quitting and even a crash, and pick up where they stopped. Updates arrive inside the app. If something goes wrong, tell us; Settings has a Copy diagnostics button that never includes links or file names.

My Android phone over USB doesn't show up on my Mac

Fuselane uses the networks macOS sees. iPhones work over USB without anything extra. Some Android phones' USB tethering needs a driver macOS doesn't include; if the phone doesn't appear under Network in System Settings, Fuselane can't see it either. On Windows and Linux, Android USB tethering usually just works.

What does Fuselane do with my data?

Nothing leaves your computer except the downloads themselves and a check for signed updates. No account, no analytics, no crash reports. Read the privacy policy.

Is it really free?

Yes, with no paid plan and nothing to sign up for. It is open source under the Apache-2.0 licence, so anyone can read and check the code.
