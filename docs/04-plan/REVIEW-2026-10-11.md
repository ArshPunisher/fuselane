## D. Extension (decided 11 Oct)

**Who downloads.**
- **App installed (open or closed):** every download goes to the app. If the app is closed, the native host starts it and the download begins there at once: no buttons, no browser download. The extension never downloads itself.
- **App not installed:** the extension downloads by itself (parallel parts on one network, resume, pause/cancel), up to a limit set in settings, **100 MB to 2 GB (default 2 GB)**. Above the limit the popup shows **Get the app** and a **Download** button that hands that one file to the browser.
- When the app does the work, it does all the saving; the extension only saves when there is no app.

**Never through Chrome (IDM-like).**
- A content script catches clicks on file links and sends them straight to Fuselane; Chrome never starts them.
- Downloads that start any other way: Chrome's download bubble is switched off while Fuselane takes over (`downloads.setUiOptions`, `downloads.ui` permission, Chrome/Edge 115+), and Chrome's copy is cancelled and erased at once. Firefox has no such switch, so a download can flash there.

**Switches.**
- **"Fuselane downloads" master switch** (settings page, and a small power button next to the gear in the popup). Off = the browser does everything; the popup then shows only a big centred **Turn on** switch. The right-click "Download with Fuselane" and "Get this page's video" stay available.
- The old "Hand big downloads to Fuselane" / smallest-size rule goes: with the app, everything goes to it.

**Popup.**
- One downloads list: the app's downloads (with the app) or the extension's own (without), with live progress and the app's combined speed; Pause / Resume / Cancel / Open / Show in folder / Remove; history.
- Speed test: with the app connected, the app's every-network speedometer; without it, a test of the browser's one connection (Cloudflare's free speed endpoints).
- Instant: state comes from the app the moment the popup opens; live updates after.

**App side needed:** local-API methods `jobs.list`, `jobs.watch`, `job.pause|resume|cancel|open|reveal|remove`, `speedtest.run`; the native host starts the app when it's closed and waits for it; every request from the extension brings the window to the front (B1).
