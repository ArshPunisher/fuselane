The browser extension now works from Microsoft Edge's store, and Fuselane has a page that shows which of your browsers have it. Beta.11 offers this update by itself: click **Update and restart**.

## Fixed

- **The extension from Microsoft Edge's store reaches the app**: the Edge Add-ons copy of the extension has its own id, which Fuselane didn't accept, so Edge kept every download for itself and the extension said Fuselane wasn't installed. Update the app (the extension needs nothing) and Edge downloads come to Fuselane again.

- **Plain words when every network fails**: a server that sends the wrong part of a file used to end with a technical dump ("BadResponse(Overrun …)"). It now says what happened, for example "the server sent bytes past the requested end". Disk problems are named the same way.

## New

- **Extension page**: a new Extension tab lists the browsers on this computer (Chrome, Edge, Brave, Vivaldi, Chromium, Firefox) and, for each, whether the extension is connected, added, turned off or missing. **Add to Edge** (or Chrome, Firefox…) opens that browser at Fuselane's page in its store; **Turn on** opens its extensions page. Fuselane only reads the browsers' settings files, it never changes them.

- **Where browser downloads go**: on the same page, choose **Everything to Fuselane**, **Small files stay in the browser** (up to 1 MB, 100 MB, 500 MB, 1, 2 or 3 GB), or **Keep downloads in the browser**. The extension follows it in every browser, and changing the switch in the extension changes it here too.

- **Add it on first launch**: the welcome tour has a step for adding the extension, and Downloads shows a small banner until a browser has it (dismiss it with **Not now**).

- **Made by ClearCraft Labs**: Fuselane's publisher is now ClearCraft Labs, shown in Windows' installed apps and in Settings → About.

## Browser extension 0.3.0

The extension has its own update, through the browser stores:

- A new look that matches the app, with a status chip (Connected, App closed or No app).
- Without the app it offers it, with a link to fuselane.app/download; with the app closed, **Open Fuselane** starts it.
- It tells the app which browser it's in, and follows the app's setting for where downloads go. A change you made while the app was closed, or before this version, is kept and sent to the app.
- Firefox 140 or newer.
