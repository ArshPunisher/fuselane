Notes for the next beta, filled in as changes land.

## New

- **Proxy passwords in your system's keychain**: a proxy's password is now kept in the macOS Keychain, Windows Credential Manager or the Linux Secret Service, not in Fuselane's settings. Passwords saved by an earlier version move there by themselves. Where there's no keychain to use, the password stays in Fuselane's settings as before, and the proxy form says so. On macOS, after an update, the system may ask once whether Fuselane can use the saved password: choose **Always Allow**.

- **More Hindi**: with हिन्दी chosen, messages from Fuselane's core now show in Hindi too: why a download failed and what to do, errors in the New download dialog and in Settings, proxy and network notes, and feed, folder, Nearby and update problems. Details that come straight from your system stay in English.

- **Speedtest, with its own tab**: a live, colourful speedometer measures each network the way public speed tests do: several connections at once for a few seconds, leaving out the slow start, so the figures match what speed-test sites show (the old check under-counted, often by half). It now measures upload too, latency while the line is busy in both directions, and shows each network's internet provider and the test server's city, then every network together. It skips a network that has used its data allowance, and the data it uses counts toward the allowance.

- **Usage, live**: Networks → Usage shows this month's total and each network's share, what's moving right now with a live line per network, the last 30 days with today growing as you watch, and a card per network with its allowance. It no longer shows a blank page when there's no day-by-day history yet.

## Fixed

- **Tabs stay put**: the Nearby/Link and Setup/Usage tabs no longer jump sideways when you switch; they sit in the middle of the header.

- **Command line**: `fuselane get` refuses a save folder that doesn't exist (or a file given as the folder) before saving anything, and a link over 8 KB, the same as the app.


- **Flatpak**: the Flatpak build no longer offers its own updates (your software centre updates it), starts at login and keeps the computer awake through the desktop's portals, opens links and `.torrent` files in the copy already running without an extra permission, and says plainly that the browser extension and Sleep or Shut down when done need the `.deb` or AppImage for now.

- **Fuselane always opens a window**: if Fuselane can't open its download list when it starts, it now opens a window that says why, instead of seeming to do nothing. When the list was saved by a newer Fuselane (say you ran a newer copy, then opened an older one), **Update now** downloads and installs the newer version right there, and your downloads are kept; if no update can be found, it links to fuselane.app. For any other problem (a folder Fuselane can't write to, a full disk) it shows what went wrong, with **Open the folder** and **Copy details**. This window comes with this version, so copies from before it still close without a word in that case. An older copy also no longer changes a newer copy's list while refusing it.
