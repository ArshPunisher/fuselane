Fuselane can now be updated from the command line. Beta.13 offers this update by itself: click **Update and restart**.

## New

- **`fuselane update`**: updates the Fuselane app to the newest version from a terminal, with the same signed download as **Update and restart** (over every network, checked against Fuselane's release key, then a restart). It opens the app first if it's closed, and your downloads pause and carry on afterwards. `fuselane update --check` only says whether there's a newer version.
- **`brew upgrade --cask fuselane`** now updates Fuselane like any other app installed with Homebrew.

## Fixed

- **One update at a time**: starting an update from the window while the command line was also updating could run two installs at once. Now the second one follows the first one's progress.
