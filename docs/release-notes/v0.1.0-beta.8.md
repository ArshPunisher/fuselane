Send to computers and phones nearby without a link, plus the fixes you asked for. Beta.7 offers this update by itself: click **Update and restart** (this time it's the last update without a progress bar).

## Fixed

- **Speeds add up**: a torrent's big number is now the sum of its networks, shown underneath (Wi-Fi 5.4 + Ethernet 6.4…). The sidebar total says it counts all downloads together.
- **Remove asks and waits**: Remove opens a dialog that stays until you choose Cancel, Keep files or Move files to Trash. Torrent files now go to the Trash instead of being deleted outright.
- **No scrollbar in the link box**: one link is one line; a pasted magnet becomes a card with its name and a Change button.
- **Updates show their size and progress**, with a bar, megabytes, speed and time left. Fuselane downloads them over all your networks, checks the signature, and offers Try again if something goes wrong.

## New

- **Nearby**: on the Send page, computers and phones on your network appear by themselves. Pick one and send. A new device shows four words on both screens to check first; trust it and its files arrive without asking. Works with the free LocalSend app on phones, and a phone without any app can scan a code and send or receive in its browser.
- **Torrent files**: give each file High, Normal, Low or Skip, see how much of each has arrived, and **Play** a video or song while it downloads.
- **Mirrors**: add other links to the same file under More options; each is checked to be the very same file, then every network downloads from all of them.
- **Start at a set time**: under More options, choose when a download starts. It waits in your list and starts by itself.
- **When a name is taken**: Fuselane asks whether to keep both or replace the old file (or set a default in Settings).
- **When a download finishes**: open it, or unpack zip and tar archives, by itself (Settings).
- **Filter by type** in your list: video, music, archives, apps and more.

Please report problems at https://github.com/ArshPunisher/fuselane/issues.

## Install

| System | File |
|---|---|
| macOS 13.3+ (Apple silicon and Intel) | `Fuselane_<version>_macos-universal.dmg`, or run the install script below |
| Windows 10/11 (x64) | `Fuselane_<version>_windows-x64-setup.exe` |
| Linux x64 | `.AppImage`, `.deb` or `.rpm` ending in `linux-x64` |
| Linux arm64 | `.deb` or `.rpm` ending in `linux-arm64` |
| Command line | `fuselane-cli_<version>_<system>` |

**macOS:** the app is open source and ad-hoc signed, not notarized (no paid Apple account, by policy). The install script does the one-time setup for you:

```sh
curl -fsSL https://raw.githubusercontent.com/ArshPunisher/fuselane/main/packaging/macos/install.sh | sh
```

**Windows:** until code signing is approved, SmartScreen may say "Windows protected your PC". Choose **More info → Run anyway**.

## Verify

Every file's SHA-256 is in `SHA256SUMS`. For example: `shasum -a 256 -c SHA256SUMS --ignore-missing`.
