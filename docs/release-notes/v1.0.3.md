Fuselane 1.0.3 is a small security update. Click **Update and restart**.

## Safety

- **A library update for web addresses.** The `url` library Fuselane uses had a flaw (RUSTSEC-2026-0592): an address with thousands of nested `blob:` prefixes could crash a program that asked for its origin. Fuselane itself never asks for an address's origin, so it was not directly affected, but it now ships the fixed library so no part of the app can reach that path.
