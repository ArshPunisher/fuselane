The fourth beta: torrents, the browser extension, and Wi-Fi sign-in pages. Beta.3 offers this update by itself: click **Update and restart**.

## New

- **Torrents**: open magnet links and `.torrent` files (paste, drop, or "Open with" from your system). Each torrent uses every network, shows which network brought how much, lets you pick files, and resumes after a restart. Speed limits, Slow mode and data allowances apply to torrents too. Sharing after a download finishes is off unless you turn it on, with ratio and time limits and a guard for metered networks.
- **Browser extension support**: the Chrome extension (in review on the Chrome Web Store) hands big downloads to Fuselane. The app sets itself up for Chrome, Edge, Brave, Vivaldi, Chromium and Firefox every time it starts; nothing else to install. If Fuselane can't take a download, the browser keeps it.
- **Wi-Fi sign-in pages**: hotel and café networks that need you to sign in show "Sign in needed" and are left out of downloads until you do.
- **Look up servers through each network** (Settings, off by default), for networks with their own DNS.
- **Free space check** before a download starts, with a clear message.
- **Command line**: `fuselane ls --json`, `fuselane nets --json`, and `fuselane browsers` to set up the extension without the app.

## Fixed

- A busy download list could be mistaken for a damaged one and set aside, which hid your downloads. Only a really damaged file is set aside now.
- The app and the command line can no longer run the same download at once.
- A server on this computer works even when no network is usable.
- Windows: a Hyper-V network adapter is recognised as a real network.
- The details pane fits on 1280-pixel laptop screens.
- Orange status text is easier to read in light mode.

Please report problems at https://github.com/ArshPunisher/fuselane/issues.

## Install

| System | File |
|---|---|
| macOS 13.3+ (Apple silicon and Intel) | `Fuselane_<version>_macos-universal.dmg`, or run the install script below |
| Windows 10/11 (x64) | `Fuselane_<version>_windows-x64-setup.exe` |
| Linux x64 | `.AppImage`, `.deb` or `.rpm` ending in `linux-x64` |
| Linux arm64 | `.deb` or `.rpm` ending in `linux-arm64` |
| Command line | `fuselane-cli_<version>_<system>` |

**macOS:** the app is open source and ad-hoc signed, not notarized (no paid Apple account, by policy). The install script does the one-time setup for you:

```sh
curl -fsSL https://raw.githubusercontent.com/ArshPunisher/fuselane/main/packaging/macos/install.sh | sh
```

**Windows:** until code signing is approved, SmartScreen may say "Windows protected your PC". Choose **More info → Run anyway**.

## Verify

Every file's SHA-256 is in `SHA256SUMS`. For example: `shasum -a 256 -c SHA256SUMS --ignore-missing`.
