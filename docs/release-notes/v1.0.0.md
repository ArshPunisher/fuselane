Fuselane 1.0 is the first stable release. It's the same app as beta.18, after 18 betas of fixes from real use. Beta users get it by themselves: click **Update and restart**.

## What Fuselane does

- **One download over every network at once**: Wi-Fi, Ethernet and a USB-tethered phone, fused into one byte-exact file. Resume after a crash or restart, recovery when a network drops, a speed limit overall, per network and per download, slow mode, monthly data allowances, and hours per network.
- **Torrents** over every network too, with peers per network, a pieces strip, file choice and opt-in sharing with limits.
- **Videos from pages**: Get the video sets up its own tools on first use, with HD video and sound joined into one file, or Audio (MP3).
- **The browser extension** for Chrome, Edge and Firefox hands downloads to the app, or works on its own when the app is closed.
- **Send**: Fuse Send links, Nearby to other computers and to phones (LocalSend works too), and Continue on another computer.
- **Plan your downloads**: queue, groups, Download later, start at a set time, Ready by, mirrors, Metalink, feeds, and retries by themselves.
- **Command line** (`fuselane`) and remote control for aria2 apps.
- **Signed auto-updates**, Report a problem, English and Hindi, and light and dark themes. No telemetry and no account.

## Known limits

- **Windows**: the installer isn't code-signed yet (signing is applied for), so SmartScreen may warn the first time.
- **macOS**: ad-hoc signed and not notarized, as a matter of policy. Use the install script or Homebrew.
- Torrent DHT and UDP tracker traffic uses the system's default network and isn't counted toward data allowances.
- Phone tethering is tested on macOS. Windows and Linux have had less testing on real hardware, so please report what you find.

Please report problems with **Settings → Report a problem**, or at https://github.com/ArshPunisher/fuselane/issues.
