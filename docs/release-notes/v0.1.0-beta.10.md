Built-in tools that usually need a separate app, all free and on your computer only. Beta.9 offers this update by itself: click **Update and restart**.

## New

- **Videos from pages**: paste a YouTube (or one of 1,000+ sites) link and choose **Get the video from this page**. Pick a quality, or **Audio (MP3)**, and Fuselane downloads it over every network at once. Needs the free yt-dlp tool (and ffmpeg for HD and MP3); Fuselane never bundles them. In the browser, the extension's button does the same in one click.
- **Network check** (Networks): each network's speed, delay, jitter, how it copes when busy (graded A+ to F) and name lookups, then every network together. Fuselane also notes every outage, and makes a dated report you can send your internet provider.
- **Data used** (Networks): what each network carried this month, and a 30-day chart.
- **Hours per network**: use a network only between set times, for example the phone from 23:00 to 06:00 on a night plan. Downloads move over by themselves when a window opens or closes. **Before midnight** sets 22:00 to 00:00: with a daily allowance, downloads use what's left of today's data before it expires.
- **Text between your computers** (Send): send what you copied to another computer. From a trusted one it lands straight on the clipboard. Works with LocalSend on phones too.
- **Folders**: drop a folder on a device to send it as a folder, or keep a folder in sync with your other computer. New and changed files go across whenever both are on your network; nothing is deleted there, and there's no cloud.
- **Feeds** (Downloads → Feeds): follow a podcast, a project's releases or any RSS or Atom feed. New files download by themselves, named after their titles, with words to include or skip. Torrents in a feed wait for you to open them, unless you tick **Start torrents by themselves** for that feed. The browser extension offers **Follow this site's feed** on pages that have one.
- **Phones without the app can send text**: the phone page (Send → Show a code to scan) now takes text or a link and puts it on this computer's clipboard, and shows text you offer it to copy.
- **Remote control for aria2 apps** (Settings → Other apps, off by default): AriaNg, the Aria2 browser extensions and phone remote apps can add downloads and watch them. A secret is needed on every call, and only this computer can connect unless you allow your network. With your network allowed, scan a code to control downloads from your phone's browser. AriaNg and the phone page update the moment a download starts, pauses or finishes.
- **Metalink**: paste a `.meta4` or `.metalink` link and Fuselane downloads the files it lists, each from all its mirrors at once, and checks every file against its SHA-256.
- **Add files from a folder** (Settings → Files): a .torrent file, a Metalink or a .txt list of links put in a folder you pick starts by itself. Media tools that save .torrent files to a folder work with it.
- **A short welcome** on the first launch: the networks Fuselane found, an optional check of how fast they are together (with a plain verdict), and where to start. Settings → About shows it again.
- The Networks page is now in three tabs: **Setup**, **Check** and **Usage**.
- **Throttled networks step aside**: when a network slows to a crawl while the others keep going (a phone dropped to 64 kbps after its daily data, for example), Fuselane stops giving it work, hands its unfinished parts to the other networks, and says so on the download. It tries the network again every few minutes and lets it back in once it's fast. Slow servers and short dips don't count.
- **Proxy per network** (Networks → Setup): give one network an HTTP or SOCKS5 proxy, with a username and password if it asks. Downloads on that network go through it, https stays encrypted end to end, and the proxy is checked as soon as you save it, so a wrong address or login shows right away. Torrents still connect directly.

## Fixed

- Name lookups through each network could wait 3 seconds on networks that drop a second query; they now ask again at once.
- Settings no longer scrolls sideways in a narrow window.
- A download no longer fails when the server drops the very first connection: Fuselane asks again a few times first.
- On Linux, Fuselane is now offered for magnet links, as on macOS and Windows (it never takes them over).

Please report problems with **Settings → Report a problem**, or at https://github.com/ArshPunisher/fuselane/issues.

## Install

| System | File |
|---|---|
| macOS 13.3+ (Apple silicon and Intel) | `Fuselane_<version>_macos-universal.dmg`, or run the install script below |
| Windows 10/11 (x64) | `Fuselane_<version>_windows-x64-setup.exe` |
| Linux x64 | `.AppImage`, `.deb` or `.rpm` ending in `linux-x64` |
| Linux arm64 | `.deb` or `.rpm` ending in `linux-arm64` |
| Command line | `fuselane-cli_<version>_<system>` |

**macOS:** the app is open source and ad-hoc signed, not notarized (no paid Apple account, by policy). The install script does the one-time setup for you:

```sh
curl -fsSL https://raw.githubusercontent.com/ArshPunisher/fuselane/main/packaging/macos/install.sh | sh
```

**Windows:** until code signing is approved, SmartScreen may say "Windows protected your PC". Choose **More info → Run anyway**.

## Verify

Every file's SHA-256 is in `SHA256SUMS`. For example: `shasum -a 256 -c SHA256SUMS --ignore-missing`.
