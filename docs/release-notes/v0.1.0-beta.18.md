Two fixes from real use, plus security updates. Beta.17 offers this update by itself: click **Update and restart**.

## Fixed

- **Removing a download whose file is gone**: if you moved or deleted the file yourself, the bin icon now just takes it off the list. It no longer asks whether to keep the file or move it to the Trash, and no longer shows "The file is no longer at…".
- **Audio (MP3) leaving two files**: if Fuselane was closed while it was making the MP3, the downloaded .m4a stayed next to an unfinished .mp3. The MP3 is now written under a hidden name and only appears when it's complete, and an unfinished one is made again the next time Fuselane starts. The list says **Making the MP3…** while it works.
- **Security**: updated the certificate checks (rustls-webpki 0.103.16 and the bundled root certificates), tokio, and the updater, which no longer uses the withdrawn zip 4 release.

Please report problems with **Settings → Report a problem**, or at https://github.com/ArshPunisher/fuselane/issues.
