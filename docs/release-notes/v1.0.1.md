Fuselane 1.0.1 is a stability release: a deep review of 1.0 found and fixed crashes, lost work and a few safety gaps. Everyone should update. Click **Update and restart**.

## Fixed

- **Automatic retries and scheduled starts work again.** The first retry or "Start at" time used to stop Fuselane's background timer for the rest of the session: no more retries, schedules, data-allowance counting or keeping the computer awake. That download also stayed "running" with nothing downloading.
- **Opening Fuselane a second time no longer pauses your downloads.** On Windows and Linux, opening a magnet, a .torrent or a fuselane:// link while Fuselane was running paused everything. The command line can't pause the app's downloads either.
- **No more crashes on non-English text.** Copying a short word in Hindi, Chinese, Japanese or Korean with clipboard watching on, or opening a file from a folder like "Émile", could crash Fuselane.
- **Torrents survive starting with no network.** Starting with Wi-Fi off could make unfinished torrents disappear from the list.
- **"Remove, keep files" keeps every file you chose**, including lower-priority files still on their way.
- **Keep a folder in sync** (Nearby) no longer crashes the app.
- **A Send you stop while it's preparing stays stopped.** It used to keep sharing unseen and come back after a restart.
- **Data allowances** no longer reset to zero when you set one or change its reset day, and usage is never rounded up.
- **The app can't freeze** in a rare mix of focus mode, a schedule and a finishing download.
- **Local connections stay up.** The browser extension link, remote control and Nearby kept working only until their first network error; now they recover by themselves.
- **A blank window** after an unexpected error now shows a message with a way to reload. A screen that can't load its data says why, with Try again.

## Browser extension 0.4.3 (reaches the Chrome, Edge and Firefox stores after their review)

- Only your own clicks send links to Fuselane. A web page can't push downloads by faking clicks.
- Downloads the extension makes by itself check every part and the file's version, so a file that changes on the server is never saved corrupted.
- Private copies left behind by a failed save are cleaned up.

## Safety

- SQLite 3.54.1 and zip 9.8.1 (security updates).
- Remote control can only save into your download folder, and limits connections and batch sizes.
- Nearby ignores announcements with missing or fake device IDs, can't be flooded with made-up devices, and won't let another device take over a trusted device's address.
- Fuselane makes room for more open connections at start-up.

## Faster and lighter

- The idle download ring no longer redraws all the time, and the app stops polling and redrawing while its window is hidden.
- Pasting many links refreshes the list once instead of once per link, and the finished list shows the latest 200 with older ones on request.
