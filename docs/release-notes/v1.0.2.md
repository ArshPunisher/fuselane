Fuselane 1.0.2 makes finishing a download crash-proof and closes an update loophole. Click **Update and restart**.

## Fixed

- **A crash at the very end of a download no longer loses it.** If Fuselane, the command line or your computer stopped at the moment a finished file was being moved into place, the file could be left whole on disk but the download stuck as "running". Fuselane now notes the move before it happens and finishes it the next time it opens.
- **Killing a download right after it starts and resuming** no longer leaves a second copy, "(1)", and a large leftover part file. It carries on in the same file.
- **The command line** (`fuselane`) finishes any save a crash cut short when you open the list.
- **Recovered downloads** are sorted into their folders and replace older copies like any other finished download.
- **Unplugged drives** and unreadable folders are reported as errors instead of being treated as a missing file.

## Safety

- **Updates can never go backwards.** Fuselane only installs an update that is signed for exactly the version announced, and newer than the one you have, on every download path. A tampered or replayed update feed can't roll the app back to an older version.
