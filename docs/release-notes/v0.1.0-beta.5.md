The fifth beta: **Fuse Send**, links that redirect, and a long list of download-manager features. Beta.4 offers this update by itself: click **Update and restart**.

## New

- **Fuse Send**: send a file of any size straight from your computer. Open **Send**, pick a file and copy the link; the other person opens it and their Fuselane receives it, encrypted on the way and checked when it lands. No upload, no account, no size limit. On the same network it connects straight away; across the internet it works over IPv6, or when the sender's router has UPnP on. Shares come back after a restart with the same link, and can stop by themselves after one full copy is sent.
- **A speed limit per download**, changeable while it runs.
- **Download later**: add links without starting them.
- **Failed downloads try again by themselves** when the reason may pass (a dropped network, a busy server), and at once when a network comes back.
- **Export and import** your download list as a text file.
- **Catch copied download links** (Settings, off by default): copy a link to a file and Fuselane offers to download it.
- **Move to Trash** for finished files.
- Links with a login in them (`https://user:password@site/file`) work; the password is hidden in the window.
- Pasting or dropping a Fuse Send link anywhere opens it on the Send page; the share page's **Open in Fuselane** button opens the app.

## Fixed

- **Links that redirect** (GitHub release files, mirrors, signed download links) failed with "status 302". They're followed now, and your cookies and logins never follow to another site.
- Pausing a torrent while it was still checking could be lost, and it downloaded anyway.

Please report problems at https://github.com/ArshPunisher/fuselane/issues.

## Install

| System | File |
|---|---|
| macOS 13.3+ (Apple silicon and Intel) | `Fuselane_<version>_macos-universal.dmg`, or run the install script below |
| Windows 10/11 (x64) | `Fuselane_<version>_windows-x64-setup.exe` |
| Linux x64 | `.AppImage`, `.deb` or `.rpm` ending in `linux-x64` |
| Linux arm64 | `.deb` or `.rpm` ending in `linux-arm64` |
| Command line | `fuselane-cli_<version>_<system>` |

**macOS:** the app is open source and ad-hoc signed, not notarized (no paid Apple account, by policy). The install script does the one-time setup for you:

```sh
curl -fsSL https://raw.githubusercontent.com/ArshPunisher/fuselane/main/packaging/macos/install.sh | sh
```

**Windows:** until code signing is approved, SmartScreen may say "Windows protected your PC". Choose **More info → Run anyway**.

## Verify

Every file's SHA-256 is in `SHA256SUMS`. For example: `shasum -a 256 -c SHA256SUMS --ignore-missing`.
