Videos from web pages now work with nothing to install, on every system. Beta.14 offers this update by itself: click **Update and restart**.

## New

- **Video tools set up by themselves**: the first time you get a video from a page, Fuselane downloads yt-dlp, ffmpeg and deno into its own folder (macOS, Windows and Linux), checks each one against a pinned SHA-256, and shows the progress in New download. No terminal, no Homebrew. If you already installed yt-dlp yourself, that copy still works.
- **Open this page in Fuselane**: the browser extension's popup has a button that sends the page you're on to the app, which then offers the video and files it can get from it.

## Fixed

- **Send**: nearby computers and phones now show up within seconds. On Windows the device list could stay empty for minutes, and a Wi-Fi change could stop announcements on every network.
- **Browsers page**: the buttons just say **Add**, and the pills and buttons line up in one column.
