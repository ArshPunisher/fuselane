Ten new ways to download smarter, a redesigned Send page, and a way to tell us when something breaks. Beta.8 offers this update by itself: click **Update and restart**.

## New

- **Do this now**: give one download every network. The others wait and carry on by themselves after it.
- **Groups**: links added together stay together as one row, with one progress bar, Pause all / Resume all, and one notice when everything is done. Rename or ungroup any time.
- **Find files on a page**: paste a downloads page, pick its files by type, and get them as a group.
- **Ready by**: give a download a time it should be finished. It goes first, runs outside your schedule if it has to, and says whether it's on track.
- **The phone only for long downloads**: in Networks, choose Always, Long downloads or Never for each network. Short downloads leave your phone's data alone; long ones bring it in and carry on where they were.
- **What each network saved**: after a download, see how long it would have taken without each network ("Without iPhone USB: about 6 min").
- **Checked by themselves**: when a site publishes a SHA-256 next to the file (`.sha256`, `SHA256SUMS`), Fuselane finds it and verifies the finished file. It says **Verified**.
- **Already downloaded**: New download tells you when the same file is already on your computer.
- **Continue on another computer**: send a paused download, with everything downloaded so far, to another computer with Fuselane on your network. It carries on there.
- **Low battery**: choose to keep going, leave out the phone, or pause until you plug in (Settings).
- **Send page, redesigned**: this computer in the middle and devices around it. Drop files on a device to send them; watch them travel. The receiver can now cancel too, and the four check words are gone (devices are verified by their keys).
- **Report a problem** (Settings): opens a bug report with the diagnostics filled in, for you to read and send. If Fuselane ever closes unexpectedly, it offers to report it next time. Nothing is ever sent by itself.

## Better

- Networks and Settings use wide windows; settings are grouped.
- Smoother motion across the app, and quick clicks right after switching screens are never lost.

Please report problems with **Settings → Report a problem**, or at https://github.com/ArshPunisher/fuselane/issues.

## Install

| System | File |
|---|---|
| macOS 13.3+ (Apple silicon and Intel) | `Fuselane_<version>_macos-universal.dmg`, or run the install script below |
| Windows 10/11 (x64) | `Fuselane_<version>_windows-x64-setup.exe` |
| Linux x64 | `.AppImage`, `.deb` or `.rpm` ending in `linux-x64` |
| Linux arm64 | `.deb` or `.rpm` ending in `linux-arm64` |
| Command line | `fuselane-cli_<version>_<system>` |

**macOS:** the app is open source and ad-hoc signed, not notarized (no paid Apple account, by policy). The install script does the one-time setup for you:

```sh
curl -fsSL https://raw.githubusercontent.com/ArshPunisher/fuselane/main/packaging/macos/install.sh | sh
```

**Windows:** until code signing is approved, SmartScreen may say "Windows protected your PC". Choose **More info → Run anyway**.

## Verify

Every file's SHA-256 is in `SHA256SUMS`. For example: `shasum -a 256 -c SHA256SUMS --ignore-missing`.
